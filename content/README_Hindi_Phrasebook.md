## What This Is

A comprehensive set of Hindi medical phrasebooks for Tamil/English-speaking doctors. Every entry has **English | Hindi (Devanagari) | Romanization**, plus **(optional) audio pronunciation**. The files cover questions the doctor asks, instructions, and probable patient answers.

All files live in this folder (`D:\Anki\FN OBS\hindi\`). Audio files live in the subfolder `Hindi_Audio\`.

## 🔊 Audio Pronunciation

Every Hindi (Devanagari) entry in the tables has a **playable audio file** embedded next to it.

### How to Play
- Open any file in **Obsidian** (or any editor that renders Obsidian wiki-embeds).
- Each Hindi cell shows a small **audio player** — click it to hear the pronunciation.
- The audio uses a natural **Hindi female neural voice** (Microsoft edge-tts).

### Audio Technical Details
- **Folder:** `Hindi_Audio\`
- **Format:** MP3
- **Files:** 1704 pronunciation clips
- **Voice:** `hi-IN-SwaraNeural`
- **Naming:** `audio_0001.mp3`, `audio_0002.mp3`, ... (indexed by unique phrase; no audio is duplicated — repeated phrases reuse the same file)

### Example
In `Hindi_Medical_Phrasebook_Doctor_to_Patient.md`:

```
| English              | Hindi (Devanagari)                | Romanization           |
|----------------------|-----------------------------------|------------------------|
| What is your name?   | आपका नाम क्या है? ![[Hindi_Audio/audio_0001.mp3]] | Aapka naam kya hai?    |
```

The `![[Hindi_Audio/audio_0001.mp3]]` is what renders as the playable audio player.

### If Audio Doesn't Play
1. Make sure the `Hindi_Audio\` folder is in the **same folder as the `.md` files** (it is, by default).
2. If you copied only the `.md` files somewhere, copy the `Hindi_Audio\` folder alongside them.
3. In Obsidian, audio embeds may require the file be inside the vault. If the files are outside your vault, move the whole folder inside it.

## 🧭 How Files Interlink

- The **Main phrasebook** has a "Related Files / Cross-References" section (Section 13) linking to all 12 other files.
- Each specialty file has a small "Related files" note at the top linking back to the Main file and relevant siblings.
- Open files side by side in Obsidian (Split view) to cross-reference — e.g. Main phrasebook + Common Disease Names when discussing a diagnosis.

## 📚 Suggested Use

1. Start with the **Main phrasebook** for general history-taking & examination.
2. Open the **specialty file** that matches the patient (OB/GYN, Paeds, Mental Health, etc.).
3. Tap the **audio player** to practise/prompt pronunciation before or during the consultation.
4. Use **Colloquial vs Formal** and **Cultural Notes** to adjust tone (always use "आप/aap" form with patients).
